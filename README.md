## Requirements
Before running the tool, make sure you have the following installed:
- Python 3 (e.g., `apk add python3 py3-pip` on iSH)
- Zip/Unzip (e.g., `apk add zip unzip`)

## Installation and Usage

### 1. Extract the Tool
```bash
unzip Nuker_V1.zip
```

When prompted for a password, enter:

```
#def.tools.py-v1.0.0
```

2. Navigate to the Directory

```bash
cd Nuker_Zero
```

3. Read the Instructions

```bash
cat explain.txt
```

4. Run the Tool

Follow the instructions inside explain.txt to start the tool.
